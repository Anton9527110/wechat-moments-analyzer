# 验尸清单（部署前后各过两轮）

## 第一轮：可达与功能
- [ ] 国内手机 **流量**（非公司 Wi‑Fi）用系统浏览器打开 `http://公网IP/`
- [ ] **微信内置浏览器**打开同一地址，能否进页、能否点「开始觉察」
- [ ] 上传 2～3 张压缩后截图，能否出深度觉察（等 1～2 分钟）
- [ ] `/health` 返回 `ok: true`；故意连点超过每分钟限额，应出现中文 429，不是 Load failed

## 第二轮：密钥与安全
- [ ] 浏览器「查看网页源代码」无 `sk-`、无百炼 Key
- [ ] `curl http://公网IP/api/` 的响应与仓库中无 Key
- [ ] `/etc/wechat-moments-proxy.env` 权限为 `600`，仅 root 可读
- [ ] 安全组只放行 80（及你自己用的 SSH）；Node 只听 `127.0.0.1:8787`
- [ ] 百炼控制台已设预算即停；限流为 6/30/300（可按朋友数改）
- [ ] 故意断网或停服务时，页面报错后仍出现腾达微信引导文案

## 已知残余风险（接受或后续 dig）
- 未备案用 HTTP + IP：链路不加密，仅适合熟人试用；勿传高度敏感图
- IP 易被扫：靠限流 + 预算即停兜底
- GitHub Pages / Cloudflare 仍作海外备份，国内不作为主入口
